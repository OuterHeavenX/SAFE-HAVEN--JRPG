# SAFE HAVEN — JRPG

Independent browser JRPG project.

This repository is intentionally separate from `OuterHeavenX/SafeHaven` and shares no project history, branches, or deployment configuration with that earlier game.

Safe Haven JRPG is a dependency-free HTML5/Canvas role-playing game foundation featuring Kael, Eldenbrook, overworld exploration, random encounters, turn-based battles, XP, JP, jobs, shops, equipment, quests, Whisperwood Cave, Stoneback, and browser save/load.
